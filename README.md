
# Matrix Reloaded - Refactored Architecture

This directory contains the new, refactored version of the Matrix project.

- **/matrix-engine**: Contains the Dockerized, headless OBS service.
- **/node-m**: Contains the core application.
  - **/node-m/backend**: The new Node.js + Express backend for all business logic and database operations.
  - **/node-m/frontend**: The new Vue.js 3 + Vite frontend for the user interface.
