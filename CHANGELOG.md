# Changelog

## 0.1.0-project-brain

Initial architecture/specification package.

Key decisions:
- everything is a layer
- layer is z-index
- one global playout clock
- same-layer replacement
- different-layer coexistence
- hot atomic updates
- local/URL sources
- opportunistic preload
- GPAC CPU compositor
- WPE HTML renderer
- FFmpeg/media output
- RTMP handled by output layer
- POC required before full implementation
